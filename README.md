## Ce qu'on y trouve

Une seule page, qui va à l'essentiel :
- une intro rapide sur mon parcours
- mes projets préférés, avec un lien vers chacun
- de quoi me contacter si un projet vous trotte dans la tête

## Pour la faire tourner chez vous

Rien de compliqué. Vous clonez le repo et vous ouvrez le fichier `index.html`, c'est tout.

git clone https://github.com/adrien-cardot/Landing-Test-GitHub.git

Pas de build, pas d'installation. Juste du HTML, du CSS et un peu de JavaScript.
